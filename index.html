API keys

Everything runs on your own accounts, so you only pay for what you use. Transcribing needs the Make webhook, a Groq key and an Apify token. The knowledge base saves to the shared team database on Neon when this app has one, otherwise to your own Neon database URL below.

How to create your webhook (about 3 minutes)
  1. Sign up or log in at make.com. The free plan is enough to start.
  2. Download the scenario blueprint.
  3. In Make, open Scenarios, click Create a new scenario, then the ⋯ menu at the bottom, then Import Blueprint. Choose the file you downloaded and click Save.
  4. Click the first module (Webhooks), click Add, give it any name, and click Save. Click Copy address to clipboard, then OK.
  5. Click Save (the disk icon) at the bottom, then switch the scenario ON with the toggle. Leave scheduling at Immediately as data arrives.
  6. Paste the copied address above. It looks like https://hook.eu1.make.com/abc123…

Your Groq and Apify keys below are sent to your own scenario with each reel, so you don't need to type them into Make. Each reel uses about 10 Make operations (the free plan has 1,000 a month).

Optional: this app already has a shared team database on Neon. Leave this blank to use it, or paste your own URL to keep a separate, private knowledge base.

How to get your Neon database URL (about 2 minutes)
  1. Sign up or log in at neon.tech. The free plan is enough.
  2. Click New project. Any name works. Pick the region closest to you and click Create.
  3. On the project dashboard, click Connect. Leave the defaults (branch main, database neondb).
  4. Click Show password, then copy the whole connection string. It starts with postgresql:// and contains neon.tech.
  5. Paste it above and click Save keys. The tables are created automatically the first time you add a video.

Anyone with this URL can read and change your knowledge base, so share it only with your teammates. Everyone who pastes the same URL works on the same knowledge base.

Groq API keys (1 required, up to 3) Free at console.groq.com/keys. Click Create API Key and copy it.
Apify API tokens (1 required, up to 3) Free $5 credit each month. console.apify.com → Settings → API & Integrations, then copy the Personal API token.

Team project? Each teammate can add the key from their own account. Reels are spread across the keys, and if a reel fails, it's retried with the next key. When the keys run out, remove them and the next teammate adds theirs.
